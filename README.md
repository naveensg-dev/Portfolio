# Naveen S Gawadi – Portfolio

Personal portfolio website of Naveen S Gawadi, a CSE (AI & ML) student at AJ Institute of Engineering and Technology (VTU), Bangalore.

**Live site:** https://naveensg-dev.github.io/Portfolio

## About

This is a single-page portfolio that shows my projects, skills, education, and certifications. It is built with plain HTML and CSS and a small amount of JavaScript. There is no build step and no dependencies.

The hero section has a small interactive streak grid, inspired by my Digital Mirror project. Tap a day to mark it.

## Features

- Responsive layout that works on phones, tablets, and desktops
- Automatic light and dark mode
- Keyboard-friendly, with visible focus states
- Respects reduced-motion settings

## Projects featured

- **Digital Mirror:** a habit tracker with streaks and a real-time leaderboard, built with React.js, Firebase, Firestore, and Vercel.
- **Sensored Handicapped Stick:** an Arduino-based obstacle-detection aid for visually impaired users, built with an ultrasonic sensor and C.

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/naveensg-dev/naveensg-dev.github.io.git
   ```
2. Open `index.html` in any browser.

## Deploy

The site is hosted on GitHub Pages. To publish your own copy, push the files to a repository, then go to **Settings → Pages** and select the `main` branch and the `/ (root)` folder.
